## 1. 一句话链路

```text
标定数据  →  补偿矩阵  →  逆运动学
calibration   compensation   kinematics
     ↑                            │
     └──────  model.forward()  ───┘   ★ 唯一真值来源
```

在线四步：

```text
① p ← T;  重复 3 次: p ← T − predict(p)      → corrected
② inverse_kinematics(理想机, corrected, 当前指令, 2e-6, 2e-6)
③ real.forward(②的指令)
④ pose_residual(③的位姿, T)
```

## 2. 五个量的定义（最容易混）

| 量 | 公式 | 参考基准 |
|---|---|---|
| `q₁…q₄` | 镜面绕自身转轴的转角 | rad |
| `qf` / `Z5` | 末级光程 / L1 机械位移 | m |
| `X, Y, Z` | 焦点位置 | m |
| `α, β` | `atan2(d.x, −d.z)` / `atan2(d.y, −d.z)` | 出射方向 vs `−Z` |
| **AOI** | `atan2(hypot(dx,dy), −dz)` | 工件法线 `+Z` |
| **RotZ** | `atan2(dy, dx)`，横向量 `≤1e-10` 时**无定义** | 传播方向方位角 |

> ⚠️ `α/β` ≠ AOI ≠ RotZ。三者只在**垂直入射**时同时为 0。

## 3. 核心公式

```text
反射            d_out = d_in − 2(d_in·n) n

旋转（Rodrigues）v·cosθ + (a×v)·sinθ + a(a·v)(1−cosθ)

求交            t = (p − o)·n / (d·n)        t ≤ 0 或 |d·n| ≤ 1e-10 → 失败

残差            Δ = actual − target，角分量 atan2(sin,cos) 回绕

数值雅可比      J[:,i] = (F(q+δeᵢ) − F(q−δeᵢ)) / (upper − lower)    δ = 1e-6
                贴边时 span 会小于 2δ，必须除真实 span

等效焦距        f_eff = f_obj / 扩束倍率       75 / 3 = 25 mm

焦点落点        1° ≈ 1.309 mm/°  (= 0.075 × π/180)

光斑            d = 4 M² λ f_eff / (π w_in)    未截断高斯
瑞利长度        z_R = π w₀² / (M² λ)           w₀ = 焦斑【半径】
```

## 4. 21 项基函数（补偿矩阵的骨架）

```text
1,  x₀, x₁, x₂, x₃, x₄,
    x₀², x₀x₁, x₀x₂, x₀x₃, x₀x₄,
         x₁², x₁x₂, x₁x₃, x₁x₄,
              x₂², x₂x₃, x₂x₄,
                   x₃², x₃x₄,
                        x₄²
```

```text
x = (T − center) / scale        逐维标准化
errors(T) = features(x) @ C     C 是 21×5
项数 = (n+1)(n+2)/2 = 6×7/2 = 21   (n=5)
```

| 数字 | 值 |
|---|---|
| 系数矩阵 | **21 × 5** |
| 标定样本 | 1000（默认）/ **400**（页面） |
| 超定倍数 | 400 / 21 ≈ **19 倍** |
| 迭代轮数 | **3**（实测 2 轮内收敛，残差变化 < 1e-7） |
| 位置 / 角度容差 | **2e-6** m / rad |

## 6. ⭐ 工作域：机械行程 ≠ 可用范围

| 轴 | 工作域内上限 |
|---|---|
| `q₁` | **0.6°** |
| `q₂` | **0.7°** |
| `q₃` | **0.7°** |
| `q₄` | **1.1°** |

```text
1.309 mm/°          单轴
5.03 mm/°           两轴叠加（约 2×）
> 0.5°（单轴）      → 落点冲出 φ2.5 mm 视场半径
= 2.0°              → 抛 "Ray misses mirror 4 aperture"
```

**采样存活率（实测 4000 条候选）**：

| 结果 | 数量 | 占比 |
|---|---|---|
| 几何失败 | 217 | 5.4% |
| **超标记视场** | **3555** | **88.9%** |
| 有效 | **228** | **5.7%** |

→ **约 17.5 条候选才留下 1 条**，这就是 `maximum_attempts = n × 30` 的来历。
`angle_fraction = 0.9` + `n = 1000` 会失败（只出 409 条）。

## 7. 误差模型（工程假设，非实测）

| 字段 | 形状 | 标称 σ | 实测 RMS（seed=2026） |
|---|---|---|---|
| `position_offsets` | 4×3 | 20 µm | 16.15 µm |
| `axis_tilts` | 4×3 | 100 µrad | 54.15 µrad |
| `zero_offsets` | 4 | 50 µrad | 61.58 µrad |
| `focal_scale` | 标量 | — | 1.0002 |
| `focal_offset` | 标量 | — | 20 µm |

注入点（**加在机构上，不是加在结果上**）：

```text
center ← 镜心 + position_offset
axis   ← normalize(转轴 + axis_tilt)
normal ← rotate(法向, axis, q + zero_offset)
光程   ← qf × focal_scale + focal_offset
```

## 8. 补偿效果（独立验证集 80 点，seed+1=43，全成功 0 失败）

| 指标 | 补偿前 | 补偿后 | 改善 |
|---|---|---|---|
| **位置 RMSE** | **64.87 µm** | 0.002 µm | 99.997% |
| **姿态 RMSE** | **230.6 µrad** | 0.003 µrad | 99.999% |

标定规模边际效应（固定验证集 seed=999、60 点）：

| 规模 | 位置 RMSE（后） | 姿态 RMSE（后） |
|---|---|---|
| 400 | 0.011106 µm | 0.002475 µrad |
| 800 | 0.011107 µm | 0.002650 µrad |

系数矩阵相对差 **0.06%** → **400 样本已饱和**。

> ⚠️ **不同验证集之间的 RMSE 不能直接比较**，只能比同一验证集内的"前 vs 后"。
> ⚠️ 这些是**仿真量**，不是设备精度。无噪声拟合残差趋近 0。

## 12. 十条铁律

1. **`model.forward()` 是唯一真值来源** —— 它错了，标定/逆解/补偿全错。
2. **`α/β` ≠ AOI ≠ RotZ** —— 混用会让误差图和验收判据全部失效。
3. **机械行程 ≠ 工作域** —— ±3.75° 的机器，实际只能用 0.6°~1.1°。
4. **误差加在机构上，不是加在结果上** —— 所以必须用曲面拟合，不能"减个偏置"。
5. **21 项基函数不是装饰** —— 交叉项编码了跨维耦合，去掉就不准。
6. **必须用不动点迭代** —— `predict` 的自变量是"理想机该到哪"，不是最终目标。
7. **角分量必须 `atan2(sin,cos)` 回绕** —— 一个 ±π 跳变能污染整批训练。
8. **超工作域就停用补偿** —— 宁可说"不知道"，不给假改善。
9. **仿真残差 ≠ 实机精度** —— 无噪声拟合趋近 0，实机有噪声/漂移/滞后。
10. **`X,Y,Z` 能测、`α,β` 测不了** —— AOI 实测方案在三份资料里都不存在。
