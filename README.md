## 四个最容易踩的坑（详见笔记）

1. **XY3-100 与 XY2-100 的 CLK/SYNC 引脚是互换的**——同一根 DB25，第 1/2 脚定义相反，
   接上完全不动，但每条线量起来"都有信号"。而 XY3-100 标准原文却写着
   *"Same pinout as XY2-100(E), no hardware changes needed"*，**这句话只在数据线上成立**。
2. **校验位覆盖 19 位，不是 16 位**。`P = XOR(控制字 001, D15…D0)`——
   控制字含一个 `1`，只算 16 位数据位会得到**相反**的结果。
   两个流行开源库（`georgemihaila/xy2-100`、OPAL）都犯了这个错。
3. **电气层是 RS-422，不是 LVDS**——厂商推荐器件 AM26LS31 / UA9638 摆幅 ±2 V，LVDS 只有 ±350 mV。
4. **厂商不公开"带宽"，且引脚不兼容**——"带宽"是从时域指标反推的，量级约 0.5–1.3 kHz，
   不是网传的 1–10 kHz；X/Y 引脚厂商间可能互换，**RAYLASE ±15 V vs SCANLAB +30 V，接错可能烧设备**。
