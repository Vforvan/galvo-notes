## 5 轴振镜是什么

> ⚠️ **「5 轴振镜」在业界不是标准化术语**——至少 5 种互不兼容的用法，采购前必须问清。
> 详见 `04-光学篇/光路与系统架构/00-光路总览：从 3 轴到 5 轴.md`。

**主要两支（除了都叫 5 轴，几乎没有共同点）：**

| | **进动派：SCANLAB precSYS** | **变焦派：RAYLASE AM-MODULE III 类** |
|---|---|---|
| 5 个轴 | **x, y, z 焦点定位 + a, b 入射角** | X/Y 扫描 + Z 调焦 + 2 轴光学变焦 |
| 干什么用 | **控入射角 → 决定孔形**（正锥/倒锥/零锥度） | **改光斑大小** |
| 场镜 | ❌ 固定物镜 f=75 mm | ✅ F-θ 场镜 |
| 幅面 | **Ø2.5 mm** | 100+ mm |
| 亮点 | **≤650 Hz（39 000 rpm）** 环切，纯振镜无旋转光学件 | 幅面大，光斑可调 |

**① 进动派光路（precSYS）**：

```text
激光器 → ⑪光束调理[扩束0.25–4× + 位置调节 + λ/2 + λ/4]
       → ⑫五轴扫描(x,y,z,a,b) → ⑬分束镜 → ⑭物镜(f=75mm)
       → ⑮保护玻璃 → ⑯加工气喷嘴 → 工件
       ⑬旁路 → ⑰光束位置测量（自动精细调节闭环）
```

**② 变焦派光路（后置场镜，打标机最常见）**：

```text
① 激光器/光纤 → ② 准直镜 → ③ 变焦扩束镜组(M1 M2) → ④ 折转镜
   → ⑤ X 振镜(M3) → ⑥ Y 振镜(M4) → ⑦ 动态聚焦镜组(M5) → ⑧ F-θ 场镜
   → ⑨ 保护镜 → ⑩ 工件
```

> 另有 **pre-scan（前置聚焦）架构**：聚焦镜组放在振镜**之前**，**不需要 F-θ 场镜**
> （RAYLASE AM-MODULE III / AXIALSCAN、SCANLAB varioSCAN II PR 型）。
> 三条架构的对比见光学篇第 3 节。

- 🖼️ 光路图（变焦派）：`99-附件与下载/图片/5轴振镜光路图.svg`

  单线多轴只有 **RL3-100（6 轴）** 与 **XY3-100（DB25 版 5 轴）**。

## 从"能通信"到"打得准"：5D 补偿

> ⚠️ 协议对了、光路选对了，机器**照样打不准** —— 因为真实机有安装误差、轴倾斜、
> 角度零偏、焦距误差。**补偿就是把误差算出来、反着加回去。**

`05-五轴与补偿篇/` 是一条**可运行**的完整链路：

```text
标定数据  →  补偿矩阵  →  逆运动学
calibration   compensation   kinematics
     ↑                            │
     └──────  model.forward()  ───┘   ★ 唯一真值来源
```

| 自由度 | 含义 |
|---|---|
| `q = [q₁,q₂,q₃,q₄,qf]` | 四面振镜转角 + 末级光程 / Z5 直线位移 |
| `T = [X, Y, Z, α, β]` | 焦点位置 + 两个方向分量角 |

| 关键数字（515 nm 标准档，仿真） | 值 |
|---|---|
| 补偿前 / 后 位置 RMSE | **64.87 µm → 0.002 µm**（99.997%） |
| 补偿前 / 后 姿态 RMSE | **230.6 µrad → 0.003 µrad**（99.999%） |
| 补偿矩阵 | **21×5** 二阶多项式系数（1 常数 + 5 一次 + 15 二次） |
| 标称点雅可比奇异值 | `[2.6994, 2.1889, 1.0007, 0.0504, 0.0429]`，**秩 5** |
| 标定采样存活率 | **5.7%**（≈17.5 条候选留 1 条） |

> ⚠️ **这些是仿真量，不是设备精度。** 模型只含确定性误差，不含噪声、伺服滞后、
> 热漂移与寿命；`α/β`（相对工件表面的入射角）**现有公开资料给不出实测方案**。

## 最容易踩的坑（详见笔记）

1. **XY3-100 与 XY2-100 的 CLK/SYNC 引脚是互换的**——同一根 DB25，第 1/2 脚定义相反，
   接上完全不动，但每条线量起来"都有信号"。而 XY3-100 标准原文却写着
   *"Same pinout as XY2-100(E), no hardware changes needed"*，**这句话只在数据线上成立**。
2. **校验位覆盖 19 位，不是 16 位**。`P = XOR(控制字 001, D15…D0)`——
   控制字含一个 `1`，只算 16 位数据位会得到**相反**的结果。
   两个流行开源库（`georgemihaila/xy2-100`、OPAL）都犯了这个错。
3. **电气层是 RS-422，不是 LVDS**——厂商推荐器件 AM26LS31 / UA9638 摆幅 ±2 V，LVDS 只有 ±350 mV。
4. **厂商不公开"带宽"，且引脚不兼容**——"带宽"是从时域指标反推的，量级约 0.5–1.3 kHz，
   不是网传的 1–10 kHz；X/Y 引脚厂商间可能互换，**RAYLASE ±15 V vs SCANLAB +30 V，接错可能烧设备**。
5. **聚焦光斑有两个公式，系数差 44%** ⭐ 光学篇新增。
   `d = 1.83·λf·M²/D`（厂商标称口径）vs `d = 4λfM²/(πD)`（未截断理想高斯）。
   拿后者去质疑厂商手册"算错了"，是新手常见误判。
6. **场镜焦距有 ±1.5% 制造公差** ⭐ 光学篇新增。
   机械行程不能按名义值卡死，否则装不上或焦面不对。
7. **机械行程 ≠ 工作域** ⭐ 五轴补偿篇新增。
   转角上限写着 ±3.75°，但受 φ2.5 mm 视场限制，单轴**实际只能用 0.6°~1.1°**；
   超过约 0.5° 就出域，2.0° 时直接打不到镜面。
8. **`α/β`、AOI、RotZ 是三个不同的量** ⭐ 五轴补偿篇新增。
   `α/β` 是方向的两个分量角，AOI 是相对工件法线的单一入射角，RotZ 是方位角
   （垂直入射时**无定义**）。混用会让误差图和验收判据全部失效。
9. **仿真残差趋近 0 ≠ 实机精度高** ⭐ 五轴补偿篇新增。
   补偿后位置 RMSE 0.002 µm 是无噪声确定性模型的自洽结果；
   实机的噪声、重复性、伺服滞后、热漂移、寿命**一个都没建模**。
