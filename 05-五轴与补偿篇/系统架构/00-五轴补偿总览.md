# 🎯 五轴补偿总览：从协议到"打准"

> [!info] 一句话版本
> 前面三章回答的是三个不同的问题：
> **协议篇**答"**怎么把数发出去**"，**光学篇**答"**光路上有什么**"，
> 本篇答"**发什么数，才能打到我想去的地方**"。
>
> 前两章都对，机器照样打不准 —— 因为真实机有安装误差、轴倾斜、角度零偏、焦距误差。
> **补偿就是把这些误差算出来、反着加回去。**

---

## 1. 先把"补偿"这个词定位清楚

"振镜补偿"在不同语境下指三件完全不同的事，先分清再往下读：

| 说的是什么 | 补什么 | 在哪一层 | 本库哪里讲 |
|---|---|---|---|
| **图形标定** | 平台失真（枕形/桶形）、比例因子、正交性 | 二维图像层 | [[03-调试与排错篇/04-图形失真与标定]] |
| **光学标定** | 场镜焦距公差、场曲、焦点 Z 偏移 | 光学层 | [[04-光学篇/镜片与光学元件/02-F-θ 场镜（平场聚焦镜）]] |
| **5D 位姿补偿**（本篇） | 镜面安装位置/轴线/零位/焦距误差 → 焦点 **XYZ + 入射角 αβ** 五个自由度 | 运动学层 | 本篇 |

> [!warning] 三者不互斥，但**不能互相替代**
> 图形标定把失真正成一个二维查找表，**它管不到 Z 和入射角**。
> 本篇的 5D 补偿管的是**位姿**（5 个连续量），也不是"把方块画成方块"。
> 真机上两者通常都要做，只是做的层不同。

---

## 2. 核心：`q ↔ T` 这个映射

整个补偿链路的地基是一对映射：

```text
指令  q = [q₁,q₂,q₃,q₄,qf]       5 个控制量
位姿  T = [X, Y, Z, α, β]         焦点的 5 个自由度

正向  F(q) = T      理想机与真实机各有一套 F
逆向  F⁻¹(T) = q    只有数值解，没有闭式解
```

| 符号 | 含义 | 单位 |
|---|---|---|
| `q₁…q₄` | 四面反射镜绕各自扫描轴的转角 | rad |
| `qf` | 末级镜面交点到焦点的**光程** | m |
| `X, Y, Z` | 焦点在工作坐标系中的位置 | m |
| `α` | 出射方向相对 `−Z` 在 **XZ** 平面的倾角 `atan2(d.x, −d.z)` | rad |
| `β` | 同上，在 **YZ** 平面 `atan2(d.y, −d.z)` | rad |

> [!danger] `α`/`β` **不是** AOI，也**不是** XY3-100 的 U/W 通道
> `α`/`β` 是**光束方向**的两个分量角，来自 `atan2`。
> AOI（相对工件表面的入射角）是 `atan2(hypot(dx,dy), −dz)`，是**另一个量**。
> 两者在垂直入射时都为 0，斜入射时数值不同。混用是这一章最容易犯的错。
> 详见 [[05-五轴与补偿篇/运动学模型/02-逆运动学与雅可比]] 与 [[05-五轴与补偿篇/系统架构/07-4+1前置动态聚焦架构]]。

## 3. 为什么必须有补偿：四类误差

真实机和理想机的差别只有四类，全部可以写进一个 `MachineErrors`：

| 误差项 | 物理来源 | 形状 | 注入量级（工程假设） |
|---|---|---|---|
| `position_offsets` | 镜面装反了位置 | 4×3 | N(0, 20 µm) |
| `axis_tilts` | 转轴装歪了 | 4×3 | N(0, 100 µrad) |
| `zero_offsets` | 角度零点没对准 | 4 | N(0, 50 µrad) |
| `focal_scale` / `focal_offset` | **末级光程**的比例与零点误差 | 2 个标量 | 1.0002 / 20 µm |

> [!warning] ⚠️ 这五个数字是**工程假设，不是实测值**
> 原项目从未用仪器测过任何一台实机。量级参考的是镜片安装与电机的常规公差，
> **不要引用成"某型号振镜的实测误差"**。详见 [[05-五轴与补偿篇/标定与误差补偿/03-误差模型与真实机注入]]。

误差怎么进入正向解算（一句话）：

```text
镜心    ← 名义镜心 + position_offset
转轴    ← normalize(名义转轴 + axis_tilt)
镜面法向 ← rotate(名义法向, 转轴, q[i] + zero_offset)
光程    ← qf × focal_scale + focal_offset
```

**注意误差项是"加在机构上"的，不是"加在结果上"的。**
所以它经过反射、求交之后，对最终位姿的影响是**非线性、跨维度耦合**的 ——
一个 50 µrad 的零偏既改落点，也改入射角。这正是需要补偿的原因。

## 4. 补偿链路：五步闭环

```text
①  标定
    calibration.generate_calibration_data()
    同一批指令 q 喂给【理想机】和【真实机】，收集位姿差
              │
              ▼
②  拟合补偿矩阵
    compensation.PolynomialCompensator.fit()
    二阶多项式 21×5，最小二乘一步解出
              │
              ▼
③  在线：目标 → 修正目标
    corrected_target(T)
    不动点迭代  p ← T − predict(p)
              │
              ▼
④  在线：修正目标 → 指令
    kinematics.inverse_kinematics(理想机, corrected)
              │
              ▼
⑤  把指令交给【真实机】
    real.forward(q_correct)  →  与目标比较，算残差
```

| 模块 | 职责 | 关键约束 |
|---|---|---|
| `specifications.py` | 515 nm 规格常量表 | 单一数据源，模型与镜头都从它取值 |
| `geometry.py` | 旋转、求交、反射、方向→角度 | 失败一律抛 `GeometryError` |
| `optics.py` | 高斯光束等效物镜 | 不虚构镜片曲率/玻璃材料 |
| `model.py` | 四面镜光路正向解算 ★真值来源 | `q ∈ [−3.75°,3.75°]⁴ × [0.074,0.076] m` |
| `kinematics.py` | 5→5 有界非线性逆解 | 数值雅可比，标称点秩 5 |
| `calibration.py` | 随机采样 + 工作域过滤 | 拒绝采样，上限 `30×n` 次尝试 |
| `compensation.py` | 二阶多项式 5D 误差模型 | 21×5 系数矩阵 |
| `verification.py` | 独立验证集 RMSE | 只统计逆解成功的样本 |
| `assembly.py` | 箱体包络、五执行器假设、五镜演示追迹 | 不参与补偿求解 |
| `readout.py` | XYZ / AOI / RotZ 读数 | 固定 +Z 面坐标系 |
| `api.py` | FastAPI + Three.js 静态页 | 进程内持有全局已拟合模型 |

> `model.forward()` 是**唯一真值来源**：逆解、标定、补偿、验证全部反复调用它。
> 它错了，整条链就全错 —— 所以 [[05-五轴与补偿篇/运动学模型/01-正向运动学：镜面链与位姿解算]] 值得先读。

## 5. 两条技术路线：查表 vs 解析拟合

| | **查表法（厂商路线）** | **解析拟合（本项目路线）** |
|---|---|---|
| 误差表示 | 实测栅格 → **修正表**（correction table），查表+插值 | **二阶多项式系数矩阵 21×5** |
| 依据 | Cambridge Technology CalWizard 手册 p9-p11 | 本项目 `compensation.py` |
| 优点 | 不依赖误差机理，实测即所得 | 参数少（21 个），超定充分，推理是一步矩阵乘 |
| 缺点 | 必须实测每一个栅格点；表外要插值 | 只在标定域内可信；过二阶截断有系统残差 |
| 覆盖 | 手册只到 **2 轴 / 3 轴** | 本库 5 维 |
| 对比结论 | —— | **本项目尚未做两者的定量对比** |

> [!danger] ⚠️ CalWizard 手册**不覆盖 5 轴**，它也不是 precSYS 资料
> 它讲的是 2 轴（第 6 章 p17 起）与 3 轴（第 8 章 p62 起）扫描头。
> 引用它只能作为"厂商怎么做标定"的**对照**，不能当五轴校准的依据。
> 详见 [[05-五轴与补偿篇/标定与误差补偿/09-标定测量与实机落地路线]]。

## 6. 实测出来的数字（先看结论）

在 515 nm 标准档、400 个标定样本、独立 80 点验证集上：

| 指标 | 补偿前 | 补偿后 | 改善 |
|---|---|---|---|
| 位置 RMSE | 64.87 µm | 0.002 µm | 99.997% |
| 姿态 RMSE | 230.6 µrad | 0.003 µrad | 99.999% |

> [!danger] ⚠️ 这个数字**不能读成"实机精度 0.002 µm"**
> 仿真里只有**确定性误差**，没有噪声。多项式把确定的误差学干净，残差自然趋近 0。
> 实机还有伺服滞后、热漂移、重复性、寿命衰减 —— 这些**一个都没建模**。
> 拿 0.002 µm 去跟供应商谈指标，是这一章最严重的误读。
> 完整边界见 [[05-五轴与补偿篇/标定与误差补偿/06-补偿验证与实测数据]]。
