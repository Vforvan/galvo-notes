坐标系与 AOI / RotZ 定义

读数跟随当前视图和所选镜组状态，显示完整光路的最终焦点，不随逐段显示、束径放大或相机旋转改变。五镜视图使用装配坐标（箱体入口面 X=0、宽度中线 Y=0、箱体下沿 Z=0）；原补偿光路使用自身等效坐标，不可直接混合两组 XYZ。

暂按水平工件、表面法线 +Z。AOI = atan2(√(dx²+dy²), −dz)，方向 d 取物镜之后朝焦点传播的主光线。RotZ = atan2(dy, dx)，范围 −180°～180°，从 +X 朝 +Y 为正；它是入射方位角，不是绕光轴自转或偏振角。垂直入射（横向方向量 ≤ 10⁻¹⁰）时显示“—”。位数仅为显示精度，不代表实机精度。
