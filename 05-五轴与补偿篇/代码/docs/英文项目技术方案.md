# Five-Axis Galvanometer Digital Twin & 5D Compensation Research Platform

## 1. Project Goal

Develop a Python + Three.js based five-axis galvanometer digital twin
platform for researching:

1.  Five-axis galvanometer optical kinematics
2.  Beam pose calculation
3.  Five-axis inverse kinematics
4.  Artificial error injection
5.  Calibration data generation
6.  Unified 5D (XYZαβ) compensation

The project does not initially implement: - Complete CAM system - G-code
parser - Real XY2-100 communication - Physical hardware connection

The current goal is to build a controllable virtual five-axis
galvanometer system:

Ideal machine → Error machine → Calibration → Compensation → Accuracy
verification

# 5. Optical Model

Ray representation:

    r(t)=o+t*d

Mirror reflection:

    d_out = d_in - 2(d_in·n)n

Each mirror contains:

-   Position
-   Normal vector
-   Rotation axis
-   Rotation angle

# 8. Inverse Kinematics

Goal:

Convert:

    XYZαβ

to:

    q1,q2,q3,q4,qf

Use:

-   Jacobian
-   Newton iteration
-   Nonlinear optimization

Equation:

    ΔT = J(q)Δq

Update:

    q_next=q+Δq

Need:

-   Convergence detection
-   Maximum iteration limit
-   Error threshold

------------------------------------------------------------------------
