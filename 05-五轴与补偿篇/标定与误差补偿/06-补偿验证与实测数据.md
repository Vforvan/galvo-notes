# 📊 补偿验证与实测数据

> [!info] 一句话版本
> 补偿做完了，问题只剩一个：**到底有没有变好、好了多少。**
> 答案用两个数表示 —— **位置 RMSE** 与**姿态 RMSE**，补偿前后各算一次。
>
> 但这一篇真正重要的不是那两个漂亮的数字，而是**它们不意味着什么**。

---

## 1. 验证协议：训练集与验证集必须分开

```text
训练   seed = 42     400 样本
   │
   └─ 拟合出 C (21×5)、center、scale

验证   seed = 43     80 样本     ← seed + 1，独立采样
   │
   ├─ 只统计【逆解成功】的样本
   ├─ 报告 成功数 / 失败数
   └─ 输出 补偿前 RMSE 与 补偿后 RMSE
```

| 分离手段 | 做法 |
|---|---|
| 不同随机种子 | `seed` 训练、`seed + 1` 验证 |
| 独立采样命令 | 验证集**重新**随机生成指令，不复用训练指令 |
| 只统计成功样本 | 逆解失败的不计入 RMSE（否则失败会被当成"误差很大"） |
| 报告失败数 | 让人知道成功率，而不是只看到好看的 RMSE |

> [!tip] "只统计成功的样本"是双刃剑
> 好处：不会把"解不出来"混进精度指标。
> 风险：**如果失败率很高，RMSE 只反映"能解出来的那部分"**。
> 所以必须**同时报失败数**，本项目实测 80 点全部成功、0 失败。

---

## 2. 实测结果（515 nm 标准档，400 训练 / 80 验证）

| 指标 | 补偿前 | 补偿后 | 改善 |
|---|---|---|---|
| **位置 RMSE** | **64.87 µm** | **0.002 µm** | **99.997%** |
| **姿态 RMSE** | **230.6 µrad** | **0.003 µrad** | **99.999%** |

验证集：80 点，由 `seed + 1 = 43` 单独采样，**全部成功、0 失败**。

### 2.1 这两个数说明什么

| 结论 | 依据 |
|---|---|
| 二阶多项式**足够表达**这个模型的误差结构 | 残差降了 5 个数量级 |
| 误差确实随位姿**平滑变化**，没有高频成分 | 否则二阶拟合不会这么干净 |
| 补偿链路（拟合 + 不动点迭代 + 逆解）**实现正确** | 前 2 轮迭代即收敛，残差变化 < 1e-7 |

> [!danger] ⚠️ 但这两个数**不能**说明的话，比能说明的更重要
> 见下面第 4 节。

---

## 3. 标定规模的边际效应：400 已经接近饱和

固定验证集（`seed = 999`、60 点、与训练同域）：

| 标定规模 | 位置 RMSE（补偿后） | 姿态 RMSE（补偿后） |
|---|---|---|
| **400 样本** | 0.011106 µm | 0.002475 µrad |
| **800 样本** | 0.011107 µm | 0.002650 µrad |

两者**系数矩阵相对差仅 0.06%**；位置残差在小数点后第 5 位才有区别，
姿态残差差 **0.000175 µrad**。

> [!tip] 这张表的实用结论
> **400 样本对这个模型已经饱和，加倍样本不会带来可见改善。**
> 原因：待求参数只有 21 个，400 个方程已经是 **19 倍超定**。
> 再加样本只是继续平均掉噪声 —— 而仿真里**本来就没有噪声**。
>
> **实机上结论会不同**：实测有噪声，更多样本确实有帮助
> （但边际收益递减，且受漂移限制）。

> [!warning] 注意两张表的 RMSE 不一样（0.002 vs 0.011 µm）
> 因为**验证集不同**：第 2 节是 `seed=43` / 80 点，
> 第 3 节是 `seed=999` / 60 点、且约束"与训练同域"。
> **不同验证集之间的 RMSE 不能直接比较**，
> 只能比较**同一验证集内**"补偿前 vs 补偿后"。
> 这是精度报告里最常见的错误引用方式。

---

## 4. ⚠️ 边界声明：这些数字**不是**设备精度

> [!danger] 把 0.002 µm 读成"实机精度 0.002 µm"是这一章最严重的误读
> **仿真里只有确定性误差，没有噪声。**
> 多项式把一套*确定的*误差结构学干净，残差自然趋近于 0。
> 这**只证明模型内部自洽**，不证明任何实机性能。
>
> 以下内容**全部没有建模**：

| 未建模项 | 影响 |
|---|---|
| **随机噪声 / 重复性** | 决定实际能达到的精度下限 |
| **650 Hz 环切能力** | 动力学，不是几何 |
| **伺服响应与滞后** | 跟随误差、动态滞后 |
| **热漂移** | 标定完成后数小时内的漂移 |
| **寿命衰减** | 轴承磨损、镀膜老化 |
| **编码器量化** | 含 XY2-100 的 16 bit 上限 |
| **镜面面型误差** | 平面度、曲率偏差 |

> [!warning] 原项目文档的原话
> *"无噪声拟合得到很小残差不意味着实机具备该精度；650 Hz、伺服响应、
> 滞后、热漂移和寿命没有建模。"*
> *"模型仅包含确定性误差，仿真残差不能当作设备实际精度。"*

### 4.1 该怎么读这些数字

| 想用它说明 | 可以 / 不可以 |
|---|---|
| "补偿算法实现正确" | ✅ **可以** |
| "二阶多项式适合这个误差结构" | ✅ **可以** |
| "400 样本已经饱和" | ✅ **可以**（仅限本模型） |
| "本方法能把实机精度提到亚微米" | ❌ **不可以** |
| "该型号振镜精度是 0.002 µm" | ❌ **不可以**，且严重误导 |
| "补偿能把实机误差降低 99.997%" | ❌ **不可以**，改善幅度取决于误差结构 |

## 5. 图上看到的是什么

页面上有三条光路 / 两组误差图：

| 元素 | 含义 |
|---|---|
| **理想机光路** | 目标位姿对应的光路 |
| **真实机执行原指令** | 未补偿，误差最大的那条 |
| **真实机执行补偿后指令** | 补偿后的结果 |
| 误差图 | XY / XZ **位置**误差（μm）+ αβ **姿态**误差（μrad），**以目标为零点** |

| 行为 | 说明 |
|---|---|
| 可选"补偿残差特写" | 把补偿后的小残差单独放大看 |
| 被刻度裁切的点 | 会**明确提示**，不静默丢弃 |
| 表格 | 给出五个误差分量及范数，小残差用科学计数法 |
| 超工作域 / 逆解失败 | **不显示补偿后结果**（不给假改善） |
| 验证样本 | 独立采样、限制在标定域内，**报告成功数与失败数** |

> [!tip] 看图的正确姿势
> 补偿后残差比补偿前小 **4~5 个数量级**，所以**两组数据不可能在同一坐标里都看清**。
> 页面用"补偿残差特写"切换，而不是自动缩放 ——
> **自动缩放会让人误以为补偿后误差还有原来那么大。**

```bash
cd 05-五轴与补偿篇/代码

```

自己复现一遍第 2 节的表：

```bash
.\.venv\Scripts\python -c "
from five_axis_galvo.model import create_default_machine as D, create_seeded_real_machine as R
from five_axis_galvo.calibration import generate_calibration_data as G
from five_axis_galvo.compensation import PolynomialCompensator
from five_axis_galvo.verification import verify_compensation
import numpy as np
ideal, real = D(), R()
train = G(ideal, real, sample_count=400, seed=42)
comp = PolynomialCompensator().fit(train)
hold = G(ideal, real, sample_count=80, seed=43)
m = verify_compensation(ideal, real, comp, hold.commands)
print('n =', m.sample_count)
print('pos  before %.2f um   after %.4f um' % (m.position_rmse_before*1e6, m.position_rmse_after*1e6))
print('ang  before %.1f urad after %.4f urad' % (m.orientation_rmse_before*1e6, m.orientation_rmse_after*1e6))
"
```

> [!note] 输出的绝对数值可能与上表略有出入
> 因为验证集是**独立采样**的（`generate_calibration_data` 用拒绝采样，
> 每次调用消耗的随机数序列与样本数、过滤命中情况有关）。
> **数量级与"改善几个数量级"这个结论是稳定的**，末位小数不必对齐。
> 这也是为什么第 3 节强调"不同验证集之间不能直接比"。

## 7. 实机验证该怎么做（与本仿真完全不同）

> [!danger] 仿真的"验证"和实机的"验证"是两件事
> | | 仿真验证 | 实机验证 |
> |---|---|---|
> | 真值来源 | 真实机模型（已知） | **必须实测** |
> | 噪声 | 无 | 有，且是主要限制 |
> | 重复性 | 完全重复 | 每次不同 |
> | 你能得到的指标 | RMSE（精确） | RMSE ± 不确定度 |
>
> 实机验证的最小可行方案：
>
> ```text
> ① 选一组【不参与标定】的目标位姿
> ② 用补偿后的指令打点
> ③ 用测量设备测实际落点（XY 与 Z）
> ④ 与目标比较，得到残差
> ⑤ 重复多次，分离"系统残差"与"随机重复性"
> ```
>
> **卡点在第 ③ 步的 `α/β` 上** —— 现有三份资料都给不出实测入射角的方案。
> 详见 [[05-五轴与补偿篇/标定与误差补偿/09-标定测量与实机落地路线]]。
