# 🎲 误差模型与真实机注入

> [!info] 一句话版本
> 理想机是"数学上完美"的那台；真实机是"**装歪了的那台**"。
> 两者用**同一套代码**，唯一区别是一个 `MachineErrors` 结构体：
> 镜心偏了、转轴歪了、零点跑了、光程比例不对。
>
> **补偿要学的，就是"这台机器歪了多少"。**

---

## 1. 五种误差，一张表

| 字段 | 形状 | 物理含义 | 代码里的注入点 |
|---|---|---|---|
| `position_offsets` | 4×3 | **镜心装偏了**（每面镜一个三维偏移） | `center = mirror.center + offsets[i]` |
| `axis_tilts` | 4×3 | **转轴装歪了**（每面镜一根轴的三维倾斜） | `axis = normalize(mirror.rotation_axis + tilts[i])` |
| `zero_offsets` | 4 | **角度零点没对准**（每面镜一个角偏） | `normal = rotate(normal, axis, q[i] + zero_offsets[i])` |
| `focal_scale` | 标量 | **末级光程的比例误差** | `focus_distance = q[4] × focal_scale` |
| `focal_offset` | 标量 | **末级光程的零点误差** | `… + focal_offset` |

`MachineErrors` 是 `frozen dataclass`，构造时就校验：

```text
position_offsets 必须是 (4,3)、axis_tilts 必须是 (4,3)、zero_offsets 必须是 (4,)
三者必须全部有限（不允许 NaN / inf）
focal_scale 必须有限且 > 0        ← 负焦距没有物理意义
focal_offset 必须有限
```

> [!danger] **"四面镜"是硬编码的**
> 校验里写死了 `(4,3)` / `(4,)`，`MachineModel.__post_init__` 也写死
> `if len(self.mirrors) != 4: raise ValueError("A five-axis model requires four mirrors")`。
>
> **这不是五轴模型的通用实现**，而是"**四面镜 + 一个等效光程**"这一种拓扑的实现。
> 换成五个真实旋转轴（如 precSYS 的实机），这套数据结构要重写。

---

## 2. 注入量级：它们是"工程假设"，不是实测

真实机由 `create_seeded_real_machine(seed=2026)` 生成：

| 误差项 | 分布 | 标称 σ | 实测 RMS（seed=2026 那一组） |
|---|---|---|---|
| `position_offsets` | N(0, 20 µm) | 20 µm | **16.15 µm** |
| `axis_tilts` | N(0, 100 µrad) | 100 µrad | **54.15 µrad** |
| `zero_offsets` | N(0, 50 µrad) | 50 µrad | **61.58 µrad** |
| `focal_scale` | 常数 | — | **1.0002**（即 200 ppm） |
| `focal_offset` | 常数 | — | **20 µm** |

> [!danger] ⚠️ 这五个数字**没有任何实测依据**
> 原项目的 README 与文档都写明：这些是**注入用的工程假设**，
> 参考的是镜片安装、电机装配的常规公差量级。
>
> **不要引用成"某型号振镜的实测误差"，也不要用它们反推设备精度。**
> 真要定这些数，只能靠实机测量 —— 路径见
> [[05-五轴与补偿篇/标定与误差补偿/09-标定测量与实机落地路线]]。
>
> 为什么"实测 RMS"比标称 σ 小？
> 因为 RMS 是**这一组样本**的统计量，不是分布参数。`n=4`（`zero_offsets`）
> 甚至只有 4 个数，`61.58 µrad` 与 σ=50 µrad 的偏差完全正常。

## 3. 误差是"加在机构上"的，这才是关键

看代码顺序 —— 误差全部**在求交之前**就并进几何里了：

```text
center  ← 名义镜心 + position_offset          ← 改的是【镜面位置】
axis    ← normalize(名义转轴 + axis_tilt)      ← 改的是【旋转所绕的轴】
normal  ← rotate(名义法向, axis, q + zero)     ← 改的是【镜面的朝向】
        ↓
hit     ← intersect_ray_plane(origin, direction, center, normal)
direction ← reflect(direction, normal)
```

**误差不直接加到落点上，而是加到机构上，经过反射链传播出去。**

这带来三个后果：

| 后果 | 说明 |
|---|---|
| **跨维度耦合** | 一个 50 µrad 的零偏**同时**改落点和入射角 |
| **位置相关** | 误差对位姿的影响**随工作点变化**，不是固定偏置 |
| **非线性** | 因而不可能用"减一个常数"修好 → 必须用曲面积合 → **这就是 21 项二次基函数的由来** |

> [!tip] 一句话记住为什么需要"矩阵"而不是"加个偏置"
> 如果误差是恒定偏移，减掉就行，不需要 21 个系数。
> 正因为误差**随位姿二次变化**，才需要 `errors(T) = features(x) @ C`。

## 4. 两种机器，同一套代码

```python
create_default_machine(errors=None)              # 理想机（errors 全零）
create_default_machine(errors=MachineErrors(…))  # 真实机
create_seeded_real_machine(seed=2026)            # 便捷封装：固定种子生成真实机
```

| | 理想机 | 真实机 |
|---|---|---|
| 镜面几何 | 同一组名义镜心/法向/转轴 | **完全相同** |
| 误差 | `MachineErrors()` 全零 | 注入上表五项 |
| 用途 | 逆解目标、生成"应该到哪" | 执行指令、生成"实际到哪" |
| 标定中的角色 | 提供 `ideal_poses` | 提供 `real_poses` |

> [!note] 两台机器共用 `create_default_machine`
> 这是刻意的设计：**唯一的差别只有 `errors`**，
> 所以标定数据里的 `real − ideal` 一定**只**反映误差，不含建模差异。
> 这让仿真实验干净，但也意味着：**仿真里不存在"模型没建对"这类误差**。

## 5. 名义光路长什么样（它是个虚拟布局）

`create_default_machine()` 的镜面中心与转轴**不在任何规格表中**：

| 项 | 值 |
|---|---|
| 光源 | `[-0.03, 0, 0.075] m`，方向 `+X` |
| M1 中心 | `[-0.01, 0, 0.075]` |
| M2 中心 | `[-0.01, 0.02, 0.075]` |
| M3 中心 | `[0.01, 0.02, 0.075]` |
| M4 中心 | `[0.01, 0, 0.075]` |
| 光路方向链 | `+X → +Y → +X → −Y → −Z` |
| 公式 | 法向由 `normalize(入射方向 − 出射方向)` 反推 |
| 镜面孔径 | 每面 **5 mm** |

> [!warning] 这是"为保证雅可比满秩而设的紧凑型虚拟光路"
> 原项目文档原话：
> *"镜面中心、初始法向和旋转轴未包含在规格表中，因此默认值是为保证五维雅可比满秩
> 而设置的紧凑型虚拟光路，**不代表厂商内部结构**。"*
>
> 接入真实设备时，应**替换**镜面中心、法向、旋转轴、行程和焦距范围，
> 并用**实测标定数据**重新训练补偿模型。
> precSYS 的公开结构与建模边界见 [[05-五轴与补偿篇/系统架构/08-precSYS五轴装配与校核边界]]。

## 6. 误差的量级到底意味着什么（量级估算）

> [!warning] 下面两段是**数量级估算**，不是严格推导
> 真实误差经过四次反射逐级传播，闭式放大系数并不简单。
> 这里只用来建立"这些 µ 级数字到底算大算小"的直觉。

**镜心偏置 σ = 20 µm 有多大？**

```text
镜心横向偏 20 µm
  → 反射链会把它按量级放大到数十 µm 级
  → 实测（seed=2026）位置 RMSE = 64.87 µm      ← 与"数十 µm"同量级 ✓
```

**角度零偏 σ = 50 µrad 有多大？**

```text
角度误差对方向的贡献本身要 ×2（反射定律）
  50 µrad × 2 = 100 µrad 的方向偏差
  × 75 mm 光程 = 7.5 µm 落点偏差（单次反射）
  → 姿态 RMSE 实测 230.6 µrad，是"µrad 级误差累积四次"的结果
```

> [!tip] 这个换算是为了说明一件事
> **姿态（角度）误差比位置误差"更难补"** ——
> 角度误差源本身就在 µrad 量级、累积四次，而角度容差通常很小。
> 实测：

| | 补偿前 RMSE |
|---|---|
| 位置 | 64.87 µm |
| 姿态 | **230.6 µrad** |

> 姿态残差是位置残差的"量级放大版"。
> 详见 [[05-五轴与补偿篇/标定与误差补偿/06-补偿验证与实测数据]]。

## 8. 这套误差模型**没有**包含什么

> [!danger] 诚实清单：以下误差**一个都没建模**
> 1. **随机噪声 / 重复性** —— 模型完全确定，同一指令永远同一结果
> 2. **热漂移** —— 温升导致的角度与焦距漂移
> 3. **伺服滞后与跟随误差** —— 这是动力学，不是几何
> 4. **迟滞与蠕变** —— 压电/机械回差
> 5. **编码器量化与非线化** —— 包括 16 bit 的 XY2-100 量化（见 [[04-光学篇/镜片与光学元件/03-动态聚焦镜组（Z 轴）]]）
> 6. **镜面面型误差** —— 平面度、曲率半径偏差
> 7. **长期寿命衰减** —— 轴承磨损、镀膜老化
>
> 这意味着：**仿真残差趋近 0，完全不等于实机精度高。**
> 见 [[05-五轴与补偿篇/标定与误差补偿/06-补偿验证与实测数据]] 的边界声明。
