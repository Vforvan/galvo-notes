# 🔌 引脚接线速查

> [!danger] ⚠️ 接线前必读
> **引脚定义厂商间不兼容！**
> - **X/Y 通道引脚可能互换**（RAYLASE 定义 X = 先被激光打到的轴）
> - **电源引脚完全不同**（RAYLASE ±15V vs SCANLAB +30V）
> - **接错可能烧设备**
>
> **换品牌必须重查它的手册。上电前用万用表逐针核对。**

---

## 一、DB25 差分信号（两家一致的部分）✅

**前 4 对线，Raylase 与 Newson 定义完全一致**——这就是"最少 4 对差分线"的由来。

| 引脚 P | 引脚 N | 信号 | 方向 |
|---|---|---|---|
| **1** | **14** | **CLK**（时钟） | 控制卡 → 振镜 |
| **2** | **15** | **SYNC**（同步） | 控制卡 → 振镜 |
| **3** | **16** | **X**（CHANNELX / CHAN1） | 控制卡 → 振镜 |
| **4** | **17** | **Y**（CHANNELY / CHAN2） | 控制卡 → 振镜 |
| 5 | 18 | Z / CHAN3 | 控制卡 → 振镜（部分厂商） |
| 6 | 19 | STATUS | **振镜 → 控制卡** ⚠️ |
| 7 | 20 | 未使用 | — |

> [!tip] 💡 只要接 1~4 对（前 8 针）就能发送数据

---

## 🚨 一、B 致命陷阱：XY3-100 的 CLK/SYNC 与 XY2-100 互换

> [!danger] 做接线前必须先确认协议版本！
> | 协议 | **Pin 1 / 14** | **Pin 2 / 15** |
> |---|---|---|
> | **XY2-100 / XY2-100E / XY2-200** | **CLK −/+** | **SYNC −/+** |
> | **XY3-100** | **SYNC −/+**（官方叫 **A**） | **CLK −/+**（官方叫 **B**） |
>
> - **帧起始边沿也相反**：XY2-100 = SYNC **上升沿**；XY3-100 = SYNC **下降沿**
> - ⚠️ XY3-100 标准写的 "Same pinout as XY2-100(E), no hardware changes needed"
>   **只在数据线上成立**，控制线是互换的
> - ✅ 唯一一致：**Z 轴在 5 / 18 脚**（RAYLASE / SCANLAB / XY3-100 三家一致）
>
> **双协议兼容板 → CLK/SYNC 必须可交换**（跳线 / 模拟开关 / 可配置差分对映射）

## 二、DB25 电源（⚠️ 厂商完全不同）

| 厂商 | POWER+ 引脚 | POWER− 引脚 | GND 引脚 |
|---|---|---|---|
| **RAYLASE (Ray-Motion)** | **9 / 10 / 22** = **+15 V** | **12 / 13 / 25** = **−15 V** | 11 / 23 / 24 |
| **SCANLAB RTC4** | **9 / 10 / 22** = **+30 V** | **12 / 13 / 25** = **GND** ⚠️ | 12 / 13 / 25 |
| **halaser E1803D 输出** | 17 / 18 / 19 = +12~24 V | 23 / 24 / 25 = −12~24 V | 20 / 21 / 22 |

> [!danger] ⚠️ 危险差异
> **RAYLASE 的 12/13/25 是 −15V，SCANLAB 的同样引脚是 GND。**
> 把 RAYLASE 定义的振镜插到 SCANLAB 控制卡上 → **可能烧设备**。
>
> **务必逐针核对，不要凭记忆插线！**

## 四、RP2040 PIO 引脚分配（XY2Galvo）

| 信号 | GPIO | 备注 |
|---|---|---|
| CLOCK+ | 8 | |
| CLOCK− | 9 | 必须与 + 相邻 |
| SYNC+ | 10 | |
| SYNC− | 11 | 必须与 + 相邻 |
| Y+ | 12 | |
| Y− | 13 | 必须与 + 相邻 |
| X+ | 14 | |
| X− | 15 | 必须与 + 相邻 |
| PIO 同步 | 16 | 单端 |
| LASER | 22 | 单端 |

> [!important] P/N 必须用**相邻 GPIO**
> PIO 的 **side-set** 一条指令可同时设置连续多个引脚，
> 这样能保证 P/N 边沿**完全对齐**。

## 五、差分驱动接线

```text
        ┌─────────────────────┐
FPGA ──>│ AM26LS31 (RS-422)   │
        │ 1A            1Y  ├──── CLK+
        │               1Z  ├──── CLK−
FPGA ──>│ 2A            2Y  ├──── SYNC+
        │               2Z  ├──── SYNC−
FPGA ──>│ 3A            3Y  ├──── X+
        │               3Z  ├──── X−
FPGA ──>│ 4A            4Y  ├──── Y+
        │               4Z  ├──── Y−
        │ GND            VCC ├──── 5V
        └─────────────────────┘
```

**一颗 AM26LS31 = 4 对信号，正好够用** ✅

## 六、推荐器件

| 用途 | 器件 | 标准 |
|---|---|---|
| 差分驱动 | **AM26LS31**、**UA9638**、AM26C31 | RS-422 |
| 差分接收（读 STATUS） | **MAX3096**、**UA9637**、AM26LV32 | RS-422 |

⚠️ **不要用 LVDS 器件**（摆幅只有 ±350 mV，RS-422 是 ±2 V）

## 七、上电前核对清单 🔬

- [ ] **确认协议版本**（XY2-100 还是 XY3-100？→ CLK/SYNC 是否互换）
- [ ] 逐针用万用表核对通断
- [ ] 确认 **P/N 没有接反**（接反 → 图形镜像）
- [ ] 确认 **STATUS 方向正确**（振镜输出 → 控制卡输入）
- [ ] 确认**供电电压**与振镜要求完全一致
- [ ] 确认**供电极性**（+V/−V/GND）
- [ ] 确认**没有双重供电**（振镜有独立电源时断开控制卡电源针）
- [ ] 确认电流需求 < 控制卡上限
- [ ] 差分线用**双绞线**且成对走线
- [ ] 终端电阻：**XY2-100 官方无规定**（线短可不加）；**XY3-100 必须加**
- [ ] 首次上电用**限流电源**（限值设正常值的 50%）

## 八、常见接线错误对照

| 错误 | 现象 |
|---|---|
| X 差分 P/N 接反 | 左右镜像 |
| Y 差分 P/N 接反 | 上下镜像 |
| X/Y 两对线互换 | 图形旋转 90° |
| CLK 接反 | 采样沿全错，通常完全不动 |
| SYNC 接反 | 帧边界识别错误 |
| STATUS 接反 | `0`/`1` 含义颠倒 → 误报故障 |
| 电源极性接反 | ⚠️ 可能烧设备 |
| 双重供电 | ⚠️ 可能烧电源或控制卡 |
| 没接 GND | 全噪声，振镜乱动 |
