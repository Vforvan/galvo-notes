## 1. 位置编码

### 基本换算

```text
发送值 = target + 32768          (target ∈ [−32768, +32767])
target = 发送值 − 32768          (发送值 ∈ [0, 65535])

中心位置: target = 0  →  发送值 = 32768 = 0x8000
```

### 角度 → 发送值

```text
归一化比例 = (θ − θ_min) / (θ_max − θ_min)
发送值     = round(比例 × 65535 + 0.5)
```

> [!danger] ⚠️ 别忘了 `+ 0.5`
> 不加会向下取整，**中心点会偏 1 LSB**（32767 而不是 32768）。

### C 代码

```c
/* 有符号 → 16 位发送值 (注意提升到 int32 防溢出) */
uint16_t xy2_encode(int16_t target) {
    if (target >  32767) target =  32767;      /* 必须钳位! */
    if (target < -32768) target = -32768;
    return (uint16_t)((int32_t)target + 32768);
}

/* 或等价地: 最高位取反 */
uint16_t xy2_encode_fast(int16_t target) {
    return (uint16_t)target ^ 0x8000;
}

/* 角度 → 发送值 */
uint16_t angle_to_wire(double angle_deg, double max_deg) {
    double norm = (angle_deg + max_deg) / (2.0 * max_deg);
    if (norm < 0.0) norm = 0.0;
    if (norm > 1.0) norm = 1.0;
    return (uint16_t)(norm * 65535.0 + 0.5);
}
```

### Python（验证用）

```python
def encode(target):
    return target + 32768

def frame(target):
    wire   = (target + 32768) & 0xFFFF
    f19    = (0b001 << 17) | (wire << 1)      # 19 位前导
    parity = bin(f19).count("1") & 1          # 偶校验: 补成偶数
    return f19 | parity

for t in (0, 32767, -32768, 1, -12345):
    print(f"{t:7d} -> 0x{frame(t):05X}  {frame(t):020b}")
```

**期望输出**（已实测验证）：
```text
      0 -> 0x30000  00110000000000000000
  32767 -> 0x3FFFF  00111111111111111111
 -32768 -> 0x20001  00100000000000000001
      1 -> 0x30003  00110000000000000011
 -12345 -> 0x29F8F  00101001111110001111
```

## 2. 校验位

```text
✅ 偶校验 (标准 16 位模式):
   P = XOR(C2, C1, C0, D15…D0)      ← 全部 19 个前导位
   使整帧 20 bit 中 1 的个数为偶数

✅ 奇校验 (增强 18 位模式):
   使整帧 20 bit 中 1 的个数为奇数
```

| 语言 | 写法 |
|---|---|
| C | `__builtin_parity(frame19)` |
| C（通用） | `for (i=1;i<=19;i++) p ^= (frame19>>i)&1;` |
| Verilog | `wire par = ^frame19[19:1];` |
| Python | `bin(f19).count("1") & 1` |

> [!danger] 两种常见错误
> ```text
> ❌ 只对 16 位数据求校验 → 因控制字含 1 个 '1', 结果必然相反
> ❌ 对全部 20 位求校验（含校验位自己）→ 恒为 0, 无意义
> ```

## 3. 分辨率

### 角度分辨率

```text
1 LSB 角度 = (θ_max − θ_min) / 65536
```

| 满量程（光学角） | 1 LSB |
|---|---|
| ±5°（共 10°） | 2.7 μrad |
| ±10°（共 20°） | 5.3 μrad |
| ±20°（共 40°） | **10.7 μrad** |
| ±25°（共 50°） | 13.3 μrad |

> [!note] 官方数据点（可作校验）
> SCANLAB：光学角 ±0.36 rad 全角程下
> - 16 bit → **11 μrad**（≈ XY2-100 的精度天花板）
> - 18 bit → 2.8 μrad
> - 20 bit (SL2-100) → 0.7 μrad
>
> RAYLASE SUPERSCAN III-10：±0.393 rad
> - 16 bit → 6 μrad 机械 / **12 μrad 光学**
> - 18 bit → 1.5 μrad 机械 / 3 μrad 光学

### 平面分辨率（结合场镜）

```text
r = f × θ                    (F-θ 场镜, θ 用弧度)
1 LSB 平面位移 = f × (1 LSB 弧度)
```

**例**：f = 160 mm，满量程 ±20° 光学
```text
1 LSB 角度 = 40° / 65536 = 1.065e-5 rad
1 LSB 位移 = 160 mm × 1.065e-5 = 1.70 μm
```

### 角度 ↔ 平面位移

```text
θ(弧度) = r / f              (r = 平面位移)
θ(度)   = (r / f) × 180/π
```

## 4. 光学角 vs 机械角 ⚠️

```text
光学角 = 2 × 机械角
```

**反射定律**：镜子转 θ，光线偏转 **2θ**。

> [!danger] 这是最容易出错的地方
> - 看到"扫描角度"必须确认是哪种角
> - 搞错 → **尺寸差 2 倍**

## 5. 帧与时序

```text
帧率 = 时钟频率 ÷ 20
      = 2 MHz ÷ 20 = 100 kHz

帧长 = 20 × 500 ns = 10 μs

SYNC 高电平时间 = 19 × 500 ns = 9.5 μs
SYNC 低电平时间 =  1 × 500 ns = 0.5 μs

比特率 = 时钟频率 = 2 Mbit/s
```

| 时钟 | 帧长 | 帧率 |
|---|---|---|
| 2 MHz | 10 μs | 100 kHz（XY2-100） |
| 4 MHz | 5 μs | 200 kHz（XY2-200） |

## 6. 有效更新率

```text
等效点速率 = 协议帧率 ÷ N          (N = 每 N 帧更新一次位置)

例: N = 100 → 100 kHz / 100 = 1 kHz 点速率
```

| N | 点速率 | 适用 |
|---|---|---|
| 10 | 10 kHz | 偏快 |
| **100** | **1 kHz** | ⭐ 常用 |
| 200 | 500 Hz | 高精度 |
| 500 | 200 Hz | 大幅面精细 |

### 带宽反推（一阶近似）

```text
f_bandwidth ≈ 0.35 / t_rise
```

**例**：阶跃响应 750 μs → `0.35 / 750e-6 ≈ 467 Hz`

> [!warning] ⚠️ 厂商不公开带宽指标
> 只给阶跃响应、跟踪误差等**时域指标**。
> "带宽"是你自己反推的，量级约 **0.5–1.3 kHz**（不是网传的 1–10 kHz）。

## 7. 延迟

### 协议固有延迟

```text
传输延迟 = 1 帧 = 10 μs
```

### 官方量化数据（RAYLASE SP-ICE 3）✅

```text
TD_TX = T_K + T_C + T_Int
  T_K   = 13 μs      常数
  T_C   = 20 μs      插值计算
  T_Int              插值周期 (T_Int=0 → TD_TX = 14 μs)

TD_RX = 36 μs        接收方向（恒定）

定位延时 = 传输延时 + 跟踪滞后
```

可通过 Enhanced 命令 **0x0556 / 0x0557** 在线读取。

### 转换器附加延迟

```text
SCANLAB XY2-100 Converter (#125377):
  附加 10 μs  →  LaserOnDelay 和 LaserOffDelay 各加 10 μs
```

## 10. 快速换算表

### 百分比 → 发送值

| 位置 | 比例 | 发送值 | Hex |
|---|---|---|---|
| 最负端 | 0.000 | 0 | `0x0000` |
| 1/8 | 0.125 | 8191 | `0x1FFF` |
| 1/4 | 0.250 | 16384 | `0x4000` |
| 3/8 | 0.375 | 24575 | `0x5FFF` |
| **中心** | **0.500** | **32768** | **`0x8000`** |
| 5/8 | 0.625 | 40959 | `0x9FFF` |
| 3/4 | 0.750 | 49151 | `0xBFFF` |
| 7/8 | 0.875 | 57343 | `0xDFFF` |
| 最正端 | 1.000 | 65535 | `0xFFFF` |

> [!note] 💡 关于 `0x1FFF` 而不是 `0x2000`
> 因为用 `比例 × 65535` 而不是 `× 65536`。
> 两者差 1 LSB，**视觉上不可见**，但要和上位机保持一致。
> 详见 [[01-协议篇/04-位置数据编码]] 第 6.1 节。
