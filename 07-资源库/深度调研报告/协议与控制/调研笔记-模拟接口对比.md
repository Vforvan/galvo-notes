### 1.2 ±5 V / ±10 V 约定的确认结论

- **±10 V** 是最经典的模拟振镜指令量程（Thorlabs 明确 ±10 V 差分；Scanner Optics STServo ±10 V Max；RAYLASE AXIALSCAN ±5 V/±10 V；Sino-Galvo SG7310 ±5 V/±10 V）。
- **±5 V** 是低量程变体：Sino-Galvo SG7310E 只支持 ±5 V；Scanner Optics UltraServo ±5 V Max；Nutfield ±5 或 ±10 VDC 出厂设定。
- **±4.8 V** 是 SCANLAB 自有量程（SCANcube 7/8.5/10/14 与 SCANcube III）。任务描述中提到的 “SCANcube 10 lists analog ±4.8 V” **已在 SCANLAB 官网与官方手册中核实**。
- 综合以上，**“±5 V 与 ±10 V 两种模拟量程并存”成立**；不同厂商、不同型号之间不通用，必须查具体型号手册。

### 3.2 模拟侧（关键一手数据）

**(a) Thorlabs 规格表明示 —— 分辨率由电源噪声决定（这是最有力的“模拟分辨率受限”证据）：**

| 条件 | 分辨率 |
|---|---|
| 配 **GPS011 线性电源** | **0.00086° （15 µRad）** |
| 配 **标准开关电源** | **0.004° （70 µRad）** |
| Repeatability | **15 µRad** |
| Linearity (50% Full Travel) | **99.9%** |
| Scale Drift | **<200 PPM/°C (Max)** |
| Zero Drift | **<20 µRad/°C (Max)** |
| 8 小时漂移 | **<0.8 mrad** |

来源：https://thorlabs-prod4us-store.govirto.com/api/thorlabs-products/support-documents/GVS011/20381-D02.pdf

推导（本报告计算）：在 0.5 V/mech° 档位，±10 V = ±20° 机械 = 40° 机械全行程 = 0.698 rad。
- 15 µrad ⇒ 0.698 / 15e-6 ≈ **46 500 个可分辨点 ≈ 15.5 bit 等效**
- 70 µrad ⇒ 0.698 / 70e-6 ≈ **9 970 个可分辨点 ≈ 13.3 bit 等效**

即：**同一块模拟驱动板，仅换电源就能把有效分辨率从 ~15.5 bit 掉到 ~13.3 bit**。这是“模拟分辨率不是被 DAC 位数限制，而是被噪声/漂移限制”的直接证据。

**(a) Thorlabs 对控制器 DAC 的建议（说明模拟链路对 DAC 的依赖）**：
`Dual bipolar -10 V to 10 V DAC analogue output channels (differential)`；`DAC clocking frequency higher than 20 kS/s (100 kS/s recommended)`；`inputs have a 7 kHz low pass filter`；`16 Bit DAC resolution and low out impedance (≤ 50 Ω)`。
- 同一 PDF，§4 “Using a DAQ Card”。

**(a) Scanner Optics** 亦给出 `Digital Signal Input Range 16bit DAC` 与 `Non Linearity of 16-Bit Digital Input 0.006%`、`Temperature Stability of Electronics 20 ppm/°C`。
- https://www.scanneroptics.com/products/analog-galvo-driver/

### 3.3 关于 “模拟 = 12 bit / 4096”

**未找到公开数据**：**没有任何厂商一手文档声明“模拟振镜接口等效 12 bit（4096）”**。可核实的等效位数只有：
- Thorlabs 实测 **≈13.3 bit（开关电源）～≈15.5 bit（线性电源）**（由 15/70 µrad 推算）；
- Thorlabs 建议控制器使用 **16 bit DAC**；
- Scanner Optics 规格以 **16 bit DAC** 为设计基准。
故「模拟 12 bit」这一常见说法**在本轮调研中无一手证据支持**，不应写进结论。

- https://www.cnblogs.com/dongxizhen/p/17026642.html

### 3.5 数字链路的“无 DAC/ADC 往返”证据

**(a) Novanta 白皮书**：数字位置检测器（encoder）把 sine/cosine **在振镜内部就数字化**，只有数字反馈信号送到伺服 —— *“the sine and cosine signals that the encoders generate are digitalized in the galvo, so only digital feedback signals are sent to the servo, which greatly reduces the sensitivity to noise”*。
- https://novanta.com/precision-manufacturing/wp-content/uploads/sites/28/2026/04/Analog_vs.Digital_Galvos.pdf

**(b) 中文技术解析（百度知道转载 Novanta 内容）**：模拟振镜驱动板直接接收并放大模拟电压信号；数字振镜接收 XY2-100 等协议数字信号，**在驱动板内部通过 DAC 转换为模拟信号再驱动电机**；**如需精确控制和远程调试，数字伺服是首选**。
- https://zhidao.baidu.com/question/2066188646363639787.html

## 5. 为什么数字接口（XY2-100 / SL2-100）取代模拟

### 5.1 厂商一手/官方声明的理由

**(a) Novanta（Cambridge Technology）白皮书 “Analog vs. Digital Galvanometer Technology – An Introduction”（©2023，作者 Matthew Tedford / Jeremy Berke / Ali Golabchi / Malte Hemmerich）** —— 原文要点：
1. **模拟伺服用大量可变电阻整定，必须逐对（servo-galvo）单独调校**：*“The control loop in analog servos use a large number of variable resistors to tune the galvo performance. This fact requires an individual tuning process for each servo-galvo pair which makes any tuning changes or replacements of individual components outside of the factory very difficult.”*
2. **无法做预测控制**：*“because the system uses potentiometers to set the tuning terms, there isn't a way to pass the values up to a system control to do predictive control.”*
3. **数字伺服可远程整定、可解耦（decouple servo from galvo）**：模拟系统出故障必须返厂 —— *“re-tuning the system can be performed in the field, whereas the analog system would have to be returned to the factory. This greatly reduces the material cost of a repair…”*
4. **可解耦序列号/产线**：模拟 galvo-servo 必须成对不分离，数字伺服允许控制柜与扫描头分线生产，最后才配对调校。
5. **模拟光学 PD 的两大缺点**：微安级电流易受 EMI；4 个分立光电池热膨胀引入 scale drift。数字 encoder PD 不受影响。
6. **对比表（Table 1）**：

   | Mirror Size Range | 3–50 mm | 3–50 mm | 14–50 mm |
   | Drift | ✔ | ✔✔ | ✔✔✔ |

### 6.2 位置检测器（PD）的物理原理与分辨率（(a)，Novanta 白皮书原文）

- **电容式 PD（capacitive）**、**光学式 PD（optical）**、**编码器（encoder）** 三种历史上都用过；现代主流是**光学式**与**编码器式**。

## 9. XY2-100 / SL2-100 协议规格（用于与模拟接口对比）

### 9.1 XY2-100（(a)，Newson/RAYLASE 官方技术数据表）

- **用途**：把 X/Y 坐标从控制器送到偏转系统。
- **电气/速率**：串行接口，**20-bit 字**，速率 **2 Mbit/s 或 100 kwords/s**；全部信号差分传输。
- **字结构**：前 3 bit 为控制字 C2–C0；随后 **16 bit 数据 D15–D0（offset binary，偏置二进制）**；最后 1 bit **偶校验 P**。`C2C1C0 = 001` 表示马达设定值。
- **SENDCK**：**2 MHz**；时钟上升沿数据变化，下降沿由偏转系统采样。
- **SYNC**：上升沿标志帧开始；保持高电平 19 bit；发送校验位时变低。
- **STATUS**（偏转系统 → 控制器，输出）：为 '0' 表示 X 轴位置误差 < 最大位置误差、Y 轴位置误差 < 最大位置误差、X 转子有效电流 < 警戒值、Y 转子有效电流 < 警戒值、数字调节器正在运行；**任一条件不满足则置 '1'**。STATUS 与 SENDCK 不同步。
- **时序**：data-in setup time tDS ≥ 50 ns；data-in hold time tDH ≥ 100 ns。
- **引脚**：1/14 SENDCK，2/15 SYNC，3/16 CHANNELX，4/17 CHANNELY，6/19 STATUS（输出），13 REF_IO。
- URL：https://e2e.ti.com/cfs-file/__key/communityserver-discussions-components-files/171/Documents_5F00_TD_5F00_XY2_2D00_100_5F00_R0703.pdf

### 9.2 XY2-100 扩展模式（(a)）

- **标准 16 bit 模式**：前 3 bit 固定 `001`，随后 D15..D0 位置数据，最后 1 bit **偶校验 Pe**。
- **增强 18 bit 模式**：第 1 bit 固定 `1`，随后 **D17..D0（18 bit）**位置数据，最后 1 bit **奇校验 Po**。
- 20 bit 帧位序：bit19…bit0。
- 常规物理接口为 DB25 插头。
- URL：https://www.aaronvose.net/Quantronix_Osprey/xy2_100_specification.pdf

### 9.3 变体与速率（(a)，sigrok 协议解码器文档）

- **XY2-100**：基础变体，时钟最高 **2 MHz**
- **XY2-200**：时钟最高 **4 MHz**
- **XY2-100E / XY2-200E**：增强变体，**可向扫描头发送附加命令**，且**用户可影响状态通道的格式**
- 常规配置：共用时钟与同步，X/Y 各一对数据 + 一对状态；有时还有 Z 轴。电气上全部差分。
- 18-bit 模式由**反相的校验位（奇校验）**指示，而 -E 变体的命令模式用默认偶校验 —— 因此**命令模式被破坏时无法与 18-bit 位置传输区分**（PD 会给出警告）。
- 状态/反馈信号至少存在 3 种变体（向后兼容 16 bit、标准 16 bit、18 bit），彼此无法自动区分。
- URL：https://sigrok.org/wiki/Protocol_decoder:Xy2-100

### 9.4 SL2-100（(a)）

- **20 bit 位置分辨率**；每个连接器最多 2 轴（SP-ICE 3）。
- 与 XY2-100 并存：RAYLASE MINISCAN III 的同一数字接口**用哪根线缆决定用哪个协议**（*“A corresponding cable defines the use of the protocol.”*）。
- **0.75 µrad** 镜面定位分辨率（20 bit，10 µs 步周期）。

## 13. 直接可用于 XY100/XY2-100 协议笔记的关键结论（要点重申）

1. **模拟接口就是“一根电压 → 一个角度”的直通链路**：Thorlabs ±10 V 差分 → ±20° 机械（0.5 V/° 默认档），Sino-Galvo 0.33 V/°、输入阻抗仅 1 kΩ，Scanner Optics 0.5/1/2 V/mech°。
2. **模拟接口的隐含信息量远小于 XY2-100**：Thorlabs 最好情况 15 µrad 等效 ≈15.5 bit，普通开关电源下降到 70 µrad ≈13.3 bit；XY2-100 固定 16 bit（11 µrad @±0.36 rad），XY2-100E 18 bit（2.8 µrad），SL2-100/RL3-100 20 bit（0.75 µrad）。
3. **模拟驱动的零点/增益漂移是硬伤**：SCANLAB 模拟伺服 <30 µrad/K、<80 ppm/K；换数字伺服后 <20 µrad/K、<20 ppm/K。
4. **模拟接口没有协议层状态回传**：XY2-100 有 STATUS 位（位置误差/电流超限/调节器运行状态），SCANLAB 数字版有位置+温度回读，RAYLASE SP-ICE-3 可回读 2400 万点日志；模拟接口只能靠驱动板另外引出的 monitor 引脚（Thorlabs J6、Scanner Optics 的位置/误差/速度/电流输出）。
5. **模拟接口的现场整定依赖电位器**：换 galvo 或 servo 必须整对返厂；数字伺服可单换、可现场重调、可把整定值上送控制器做预测控制。
6. **引脚层面**：SCANLAB 模拟接口用 25-pin D-SUB，**差分 SIG±IN1 / SIG±IN2 + PWRFAIL1/2 + ±15 V/GND**；XY2-100 也用同一 25-pin D-SUB 但换成 CLOCK±/SYNC±/CHAN1±/CHAN2±/STATUS±；TKSCAN 的 DB25 定义给的是 CLK−/CS−/X−/Y−/GND/±15V 与 CLK+/CS+/X+/Y+ 的镜像排列。**不同厂商的 DB25 定义不通用，必须逐型号核对。**
