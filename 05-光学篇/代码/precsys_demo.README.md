# precSYS 五轴微加工 · 三维原理演示

依据视频 **precSYS: 5 axis usp laser micro machining system by SCANLAB**
（[YouTube `YdydCh4l9vA`](https://www.youtube.com/watch?v=YdydCh4l9vA)）**0:18–2:50** 段的原理讲解，
配合本库《05-光学篇/16-precSYS 五轴微加工：进动架构与镜片》与 SCANLAB precSYS 数据手册制作。

## 打开方式

**双击 `precsys_demo.html` 即可**（Chrome / Edge / Firefox 均可）。

- 单文件、**零依赖、不联网**：没有 CDN、没有 npm、没有 Python 环境要求
- 3D 渲染是自写的软件渲染器（Canvas 2D + 正交投影 + 画家算法），断网也能用
- 拖拽旋转 · 滚轮缩放

## 模型说明与已知简化（重要）

### 光路几何

按视频 1:04 的 `Operating principle` 图复原：

```
光束沿 −z 竖直射入 → ⑬ 45° 分束镜折成水平 → ⑫ 两片振镜
  → 折回 ⑬ → 竖直向下 → ⑭ 物镜 → ⑮ 保护玻璃 → ⑯ 喷嘴 → 工件
```

### ⚠️ 振镜部分采用「等效偏转」模型

两片振镜的转角 → 像场位置，在数据手册里是**出厂预校准**掉的
（手册原文：*出厂校准使得可以直接在笛卡尔像场坐标系内、用米制单位描述激光运动*），
厂商**不公开逐轴几何**（笔记第 10 节明确列出「precSYS 内部 5 个振镜轴的逐轴独立规格」
属于**未找到公开来源**项）。

因此本演示对振镜采用**等效偏转**：

- 状态量为两个可验证的物理量：**像场横向位移 Δ (mm)** 与**工件入射角 AOI (°)**
- AOI 与机械倾角按反射定律取 **2:1**，上限 ±7.5°
- Δ 的上限取进动幅面 **Ø2.5 mm**
- 两轴通过一个 2×2 耦合矩阵联系（现实中两轴杠杆臂不会完全相同，故矩阵非对角占优但可分辨）

这是一处**刻意的工程简化**，代码中以 `COUP` 常量集中标注。若后续拿到厂商的逐轴规格，
只需替换这一处即可换成逐片光线追迹。

### 已知的显示压缩

焦程 ±1.0 mm 与光斑 Ø20 µm 相差 **5 个数量级**，真实比例无法同屏。
横向与轴向分别使用压缩比例（`SXY` / `SZ`），**所有读数均为真实数值**。

## 自检项（15 项）

覆盖：零位光斑居中、三段折转方向、两轴雅可比满秩（条件数）、
DOF = 2·z_R、z_R = λ/(πθ²)、光斑随离焦单调增大、自动精细调节有效性、
AOI 上限判定、角漂移误差量级对比 0.5 µm 重复性、z 焦程 ≫ 焦深、角分辨率 → 光斑步进。
