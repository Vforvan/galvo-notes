# ⚡ 差分驱动电路

> [!info] 一句话版本
> XY2-100 的电气层是 **RS-422**。FPGA/MCU 输出单端逻辑，经 **AM26LS31**（或 UA9638）
> 转成差分对送出去。**P/N 必须成对、走双绞线、两端共地。**

---

## 1. 为什么要差分

```text
【单端】一根线传信号 + 一根地线
   信号线 ────[ 2.50V + 噪声 0.3V = 2.80V ]────> 接收端读到 2.80V ❌

【差分】两根线传相反信号, 接收端读"差值"
   X+ 线 ────[ +1.8V + 噪声 0.3V = 2.1V ]────┐
                                              ├─> 差值 = 2.1 - 0.9 = 1.2V ✅
   X− 线 ────[ −1.8V + 噪声 0.3V = -0.9V ]───┘
                                              （噪声被抵消）
```

**干扰同时耦合到两根线上**（因为双绞线里两根线位置几乎相同），
接收端只关心 `V+ − V−`，噪声在相减时自动消失。这叫**共模抑制（CMRR）**。

---

## 2. 信号链路

```mermaid
flowchart LR
    FPGA["FPGA / MCU<br/>3.3V 单端"] --> DRV["RS-422 驱动器<br/>AM26LS31 / UA9638"]
    DRV -->|"CLK+ CLK−<br/>SYNC+ SYNC−<br/>X+ X−<br/>Y+ Y−"| RCV["RS-422 接收器<br/>（振镜内部）"]
    RCV --> DEC["解码 + 伺服"]
    style DRV fill:#fff4e1
    style RCV fill:#e1f0ff
```

**你要设计的部分只有左边**：单端 → 差分。

## 3. 推荐器件 ⭐

> [!success] ✅ 这是厂商推荐器件，不是我猜的
> 相关 datasheet 已归档在 `99-附件与下载/pdf/`

### 驱动器（控制卡侧）

| 器件 | 通道数 | 特点 | 备注 |
|---|---|---|---|
| **AM26LS31** ⭐ | 4 | 经典 RS-422 驱动 | 厂商推荐 |
| **UA9638** ⭐ | 2 | 双通道 RS-422 | 厂商推荐 |
| AM26C31 | 4 | AM26LS31 的低功耗版 | 兼容替代 |
| AM26LV31 | 4 | 低电压版（3.3V） | ⚠️ 注意摆幅 |
| SN75174 | 4 | 三态 RS-422 | 可挂总线 |

**推荐：AM26LS31**（4 通道，正好够 CLK/SYNC/X/Y 用一颗搞定）

### 接收器（如果你要读 STATUS）

| 器件 | 通道数 | 备注 |
|---|---|---|
| **MAX3096** ⭐ | 4 | 厂商推荐 |
| **UA9637** ⭐ | 2 | 厂商推荐 |
| AM26LV32 | 4 | 低电压版 |
| SN75175 | 4 | 带使能 |

## 4. 典型电路

### 4.1 驱动器连接

```text
        ┌─────────────────────┐
        │   AM26LS31          │
FPGA ──>│ 1A            1Y  ├──── CLK+
        │               1Z  ├──── CLK−     (1Y 与 1Z 是一对反相输出)
        │                     │
FPGA ──>│ 2A            2Y  ├──── SYNC+
        │               2Z  ├──── SYNC−
        │                     │
FPGA ──>│ 3A            3Y  ├──── X+
        │               3Z  ├──── X−
        │                     │
FPGA ──>│ 4A            4Y  ├──── Y+
        │               4Z  ├──── Y−
        │                     │
        │ GND            VCC  ├──── 5V (或 3.3V, 看型号)
        │ EN (使能)           │
        └─────────────────────┘
```

> [!tip] 💡 一颗 AM26LS31 就够
> 它有 **4 个通道**，正好覆盖 CLK / SYNC / X / Y 四对信号。
> 如果你还要 Z 轴（3D 振镜）或 STATUS 回读，再加一颗。

### 4.2 双绞线与终端匹配

```text
驱动器 ────┬──── 双绞线 (100Ω) ────┬──── 接收器
          Y+  ~~~~~~~~~~~~~~~~~  A
          Y−  ~~~~~~~~~~~~~~~~~  B
          └── 屏蔽层 ────────────┘
                    │
                  单端接地 (控制卡侧)
```

| 项目 | 要求 |
|---|---|
| 线材 | **必须双绞**（P/N 绞在一起） |
| 差分阻抗 | 约 100 Ω |
| 屏蔽 | 建议带屏蔽，**单端接地**（避免地环流） |
| 终端电阻 | ⚠️ 见下 |

> [!warning] ⚠️ 终端电阻要不要加？
> **先看官方规定，再决定：**
>
> | 协议 | 官方对端接的规定 |
> |---|---|
> | **XY2-100** | ⚠️ **标准中没有任何规定**（LIA202001 原文未提及） |
> | **XY3-100** | ✅ **官方明确要求接收端必须加终端电阻**（LIA202307） |
>
> **实证**：**两份真实的开源 XY2-100 设计都不加终端电阻**
> （XY2Galvo、hyperchao0/qspi4xy2-100 的 KiCad 原理图）。
>
> 💡 **XY2-100 的实践做法**：
> 1. **先不加**，用示波器看信号质量
> 2. 如果上升/下降沿有明显振铃或过冲 → 在**接收端**加 100~120 Ω
> 3. 线缆很短（< 30 cm）时通常不需要
> 4. ⚠️ 很多振镜内部**已集成终端电阻**，外部再加会加重驱动器负载
>
> **别盲目照抄"RS-422 必须加 120 Ω"的说法——XY2-100 标准没这么要求。**
> 但如果你做的是 **XY3-100**，那就**必须加**。

> [!danger] 🚨 做双协议兼容板：CLK/SYNC 必须可交换
> **XY3-100 与 XY2-100 在同一条 DB25 上，第 1/2 脚的 CLK/SYNC 是互换的。**
>
> | 协议 | Pin 1 / 14 | Pin 2 / 15 |
> |---|---|---|
> | XY2-100 | **CLK** | **SYNC** |
> | XY3-100 | **SYNC (A)** | **CLK (B)** |
>
> 如果你的板子要同时支持两种协议，**不能把差分对在 PCB 上绑死**——
> 需要跳线、模拟开关，或可配置的差分对映射。
>
> 详见 [[01-协议篇/08-物理层与连接器]] 第 2.5 节。

## 5. PCB 布局要点

| 要点 | 说明 |
|---|---|
| **P/N 等长** | 两条线走线长度尽量一致（偏差 < 5 mm） |
| **紧耦合** | P/N 并行走，间距均匀 |
| **不要跨越分割地** | 差分对下方地平面要完整 |
| **远离干扰源** | 远离电机驱动、开关电源、PWM 走线 |
| **阻抗控制** | 差分 100 Ω（需要时用阻抗计算工具） |
| **过孔对称** | 换层时 P/N 各打一个过孔，不要只给一根打 |
| **长度尽量短** | 建议 < 30 cm 板内，外部电缆 < 3 m 💡 |

## 6. "伪差分"方案（仅学习用）

如果只是实验，不想画板子，可以这样：

```cpp
// 用两个 GPIO 输出互补信号
void DifferentialWirePair::set(unsigned char state) {
  digitalWrite(_pinP, state == 1 ? HIGH : LOW);
  digitalWrite(_pinM, state == 0 ? HIGH : LOW);   // 反相
}
```

| 优点 | 缺点 |
|---|---|
| 零成本，接线即用 | **没有真正的差分驱动** |
| 短线上能工作 | 两个 GPIO 翻转时刻有偏差（skew） |
| 适合验证协议逻辑 | 无共模抑制能力 |
| | 驱动能力弱、边沿慢 |

> [!danger] 什么时候会出事
> - **线变长**：超过 20~30 cm 就开始不稳
> - **电机一转**：干扰耦合进来，误码率飙升
> - **多轴同时动**：地弹（ground bounce）导致逻辑误判
>
> **结论**：验证协议可以用，接真实设备请上 AM26LS31。

## 7. STATUS 回读的电路

STATUS 方向是**振镜 → 控制卡**，所以控制卡侧需要**接收器**而不是驱动器：

```mermaid
flowchart LR
    HEAD["振镜<br/>STATUS 输出"] -->|"STATUS+ / STATUS−"| RCV["MAX3096 / UA9637<br/>RS-422 接收器"]
    RCV --> GPIO["FPGA / MCU<br/>输入引脚"]
    style RCV fill:#e1f0ff
```

> [!warning] ⚠️ 如果你的控制卡要同时发和收
> 用**收发器**（如 SN65HVD 系列）或者**一颗驱动器 + 一颗接收器**。
> **不要试图用驱动器去接收**——会损坏器件。

## 8. 电源与接地

| 项目 | 说明 |
|---|---|
| 驱动器供电 | 3.3V 或 5V（看具体型号） |
| **控制卡与振镜必须共地** | XY2-100 无电气隔离 ⚠️ |
| 地线要粗 | 回流路径阻抗低 |
| 单点接地 | 避免地环流 |
| 去耦电容 | 每个芯片电源脚加 100 nF |

> [!danger] 无隔离带来的真实风险
> **RAYLASE SS-III 和 SCANLAB RTC4 的 XY2-100 接口没有电气隔离。**
> 这意味着：
> - 控制卡和振镜的"地"必须是同一个电位
> - 如果两地之间有电位差（长电缆、不同供电），**这个差值会直接加在信号上**
> - 严重时可能**损坏接口芯片**
>
> 💡 长距离或强干扰场合，自己加**数字隔离器 + 隔离电源**。

## 9. 调试检查清单 🔬

- [ ] 差分驱动器型号是 RS-422 的（AM26LS31 / UA9638）？
- [ ] P/N 是否接到了驱动器的互补输出对（Y/Z）？
- [ ] 是否用了双绞线？P/N 有没有被拆开走？
- [ ] 屏蔽层是否单端接地？
- [ ] 控制卡和振镜是否共地？
- [ ] 电源去耦电容加了吗？
- [ ] 用示波器看过差分摆幅了吗（应在 ±2 V 量级）？
- [ ] 上升/下降沿有没有振铃？需要终端电阻吗？
- [ ] 上电时用限流电源保护了吗？
