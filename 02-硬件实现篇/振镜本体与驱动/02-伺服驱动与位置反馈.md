# 伺服驱动与位置反馈

## 控制链条

`上位机轨迹 → 数字/模拟命令接口 → 振镜伺服控制器 → 功率驱动级 → 电机/镜片`，传感器将**实际轴角**反馈到伺服回路。上位机能读到什么状态，取决于厂商提供的通信协议及状态回读，不应把位置指令视为实测角度。

## 需要分开测量的量

1. **指令位置**：控制器要求的镜片/光束位置。
2. **反馈位置**：驱动器内部传感器测得的电机位置。
3. **实际焦点位置**：经过反射镜、镜片和装配误差后，在工作面上的结果。

其中第 2 项不能单独证明第 3 项已经准确；实机标定还要独立光学测量。可与 [[05-五轴与补偿篇/标定与误差补偿/09-标定测量与实机落地路线]] 对照。

接口实现参阅 [[01-协议篇/XY2-100与增强版/01-XY2-100协议总览]] 与 [[02-硬件实现篇/04-差分驱动电路]]。本页**未假设某厂商使用特定反馈传感器类型**。
