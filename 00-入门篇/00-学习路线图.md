# 🗺️ 学习路线图

> [!tip] 怎么用这张图
> 不要一次读完。**每完成一格就回来打勾**，进度看得见才不容易放弃。
> 预计总耗时：**6 周**（每天 1–2 小时）。如果只是想过一遍概念，**3 天**可以扫完 00 和 01 篇。

---

## 阶段一：建立直觉（第 1 周）

**目标**：能用大白话跟别人解释"振镜是什么、XY2-100 解决了什么问题"。

- [ ] [[00-入门篇/01-振镜是什么]] — 搞清电机、镜子、伺服三件套
- [ ] [[00-入门篇/02-为什么需要数字协议]] — 为什么不用模拟电压了
- [ ] [[00-入门篇/03-术语表]] — 混个脸熟，不用背
- [ ] [[00-入门篇/04-常见误区]] — 提前避坑

> [!success] 检验标准
> 不看笔记，画出「激光 → 振镜 → 场镜 → 工件」这条光路，并说出振镜里有哪些部件。

---

## 阶段二：吃透协议（第 2–3 周）★核心

**目标**：能在纸上手画出一个完整的 20 位帧，并算出任意位置的编码值。

- [ ] [[01-协议篇/01-XY2-100协议总览]] — 全局参数
- [ ] [[01-协议篇/02-帧结构详解]] — **最重要的一篇**，慢慢看
- [ ] [[01-协议篇/03-时序规范与参数表]] — 所有时间参数
- [ ] [[01-协议篇/04-位置数据编码]] — 动手算几个数
- [ ] [[01-协议篇/05-STATUS状态回读]] — 振镜的"体检报告"
- [ ] [[01-协议篇/06-XY2-100E增强版]]
- [ ] [[01-协议篇/07-协议家族横向对比]]
- [ ] [[01-协议篇/08-物理层与连接器]]

> [!success] 检验标准
> 1. 手写出 `X = 0`、`X = 最大值`、`X = 最小值` 三个位置的 20 位码流（含校验位）
> 2. 说明为什么 SYNC 在第 20 位（校验位）之前拉低
> 3. 说出 STATUS 为 1 时代表什么

## 🎓 学完能达到什么水平

| 能力 | 说明 |
|---|---|
| 读懂振镜说明书 | 看到 XY2-100 接口参数不再发懵 |
| 独立写驱动 | FPGA/MCU 上实现一个能跑的 XY2-100 发送器 |
| 硬件调试 | 用示波器判断时序对不对、线路有没有问题 |
| 选型 | 知道什么场合该选数字振镜、什么场合模拟够用 |
| 沟通 | 能用规范术语和厂商/同事讨论问题 |
