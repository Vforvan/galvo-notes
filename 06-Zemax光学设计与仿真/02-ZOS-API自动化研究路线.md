# ZOS-API：自动化研究路线

ZOS-API 是 OpticStudio 的自动化接口，可用于建立/修改光学系统、执行分析并读取结果；具体调用方式和许可取决于已安装的 OpticStudio 版本与授权。

## 与五轴补偿平台对接的最小闭环

1. **先人工建立并验证一个可运行的光路工程**：确定坐标系、镜片和扫描轴的参数。
2. 在当前安装版本的官方 ZOS-API 文档中核对 **交互式扩展/独立程序** 连接模式及支持的分析 API。
3. 从现有 Python 运动学平台提供一组控制量 `q`，将其映射到光学工程的镜面角度/动态 Z 位置。
4. 在 OpticStudio 中更新系统、运行分析，导出 `X,Y,Z,α,β`、光斑/光线追迹结果与截光标记。
5. 与本库 Python 模型对同一批输入比较，排查坐标约定、光学参数和数值误差。

已有 Python 平台：[[05-五轴与补偿篇/系统架构/00-五轴补偿总览]]；原理入口：[[06-Zemax光学设计与仿真/00-Zemax知识库导读]]。

**待验证项**：本机 OpticStudio 是否可用、许可证覆盖范围、对应版本的 ZOS-API 连接及具体示例能否运行。请以当前安装版的官方帮助与 API 样例为准；本页不宣称已完成自动化联机。
