# 五轴振镜光路：OpticStudio 建模与验证清单

## 先确定光学拓扑

1. 根据实物光路列出：激光源、动态调焦镜组、固定折转镜、扫描反射镜、聚焦物镜及工件面。
2. 为每块反射镜定义局部坐标和转轴；核对 **镜面机械转角与反射光线方向** 的关系。
3. 输入镜片曲率、厚度、材料、有效口径、间隔和真实安装位置；没有手册数据的参数标为**假设值**。
4. 选择与具体系统拓扑相符的顺序光线追迹或非顺序光线追迹建模方法；用单点基准光路先闭合坐标系。
5. 采样多组执行器位姿，对照独立运动学代码计算的 `X,Y,Z,α,β`，记录落点残差、入射角残差及截光状态。
6. 再引入偏心、倾斜、间距偏差和热漂移等模型扰动，观察补偿的有效工作域。

## 必须分别验证

| 指标 | 建议输出 |
|---|---|
| 几何光路 | 光线命中顺序、镜面通光口径与遮挡 |
| 焦点 | 工件面坐标、最佳焦面位置、光斑或包围能量相关分析 |
| 入射方向 | 基于出射光线的方向向量，再转换为 `α,β` / AOI |
| 误差 | 与 [[05-五轴与补偿篇/系统架构/00-五轴补偿总览]] 的理想/误差模型对比 |

**边界**：几何光线追迹结果本身不等于真实激光焦点能量分布；需要匹配光束类型及适用的物理光学分析。当前清单**未在真实软件版本上执行**。
